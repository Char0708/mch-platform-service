# Security and data boundary

This repository is an engineering sample only.

- Do not commit real, de-identified, anonymized-from-production, or manually rewritten resident or staff data.
- Do not commit production endpoints, credentials, tokens, private keys, database dumps, reports, logs, or hospital interface samples.
- Only from-scratch synthetic structural tokens may be used in tests.
- No real identity, hospital, Health Jiujiang, message, analytics, upload or production adapter may be implemented or enabled.
- The MySQL migration and container in this repository are engineering probes, not a physical business schema.
- Report security issues through a private GitHub security advisory when available. Do not place sensitive evidence in a public issue.
